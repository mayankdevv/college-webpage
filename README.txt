MARWADI UNIVERSITY - LAB 8 WEBSITE

Files:
- index.html: Main responsive webpage
- assets/pic1.jpg, pic2.jpg, pic3.jpg: Gallery images cropped from the Lab 8 output screenshot

How to use:
1. Keep index.html and the assets folder together.
2. Upload index.html and the complete assets folder to the root of your GitHub repository.
3. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).
4. Open the published URL after GitHub Pages finishes deployment.

Note: Bootstrap 5.3.3 is loaded from jsDelivr, so an internet connection is required for Bootstrap styling and the responsive navigation menu.
